夜宴牌局 · 斗地主

你和小满、阿牛三个人围坐一桌，打一副牌，全程离线。一个人当地主，另外两个当农民；地主先出牌，谁先出完，谁那一方赢。

叫分抢地主

从你开始，每人依次叫一次分：不叫 / 1 分 / 2 分 / 3 分。后叫的人只能叫更高的分；有人叫 3 分时立即成交，直接拿走三张底牌当地主。三家都不叫就重新发牌。成交的叫分就是本局底分。

牌型

  • 单张、对子、三张：一 / 两 / 三张同点数。
  • 三带一、三带二：三张同点数，带一张单牌或一个对子。
  • 顺子：至少 5 张连续单牌，从 3 到 A，不能带 2 和王。
  • 连对：至少 3 个连续对子，同样不能带 2 和王。
  • 飞机：至少 2 个连续三张，可以不带，或带同数量的单牌 / 对子。
  • 四带二：四张同点数，带两张单牌或两个对子。
  • 炸弹：四张同点数，能压普通牌；王炸（双王）最大。

比大小

3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王。普通牌必须同牌型、同张数才能压；炸弹压普通牌，王炸压一切。

计分

单位分 = 底分 × 倍数。地主输赢双份，农民单份。每打出一个炸弹或王炸，倍数翻一倍；春天（地主一路走完，农民一张没出）或反春天（农民赢且地主只出过一手）再翻一倍。积分与战绩只保存在本机，不涉及任何真实货币。

夜宴助手

右侧记牌器实时显示每个点数还剩几张没现，0 张会变暗、只剩 1 张标红提示绝张；下方战报记录叫分、出牌、炸弹与胜负。窄屏时点顶栏「记牌」打开侧栏。

操作

点牌选中 / 取消，点「出牌」打出，点「不要」过牌，点「提示」自动选一手能出的牌。键盘 Enter 出牌，Backspace 不要；叫分时可按 0 / 1 / 2 / 3 直接叫分。顶栏「音效」可以静音。
